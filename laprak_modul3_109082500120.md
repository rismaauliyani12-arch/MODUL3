## Dasar Teori

### A. Abstract Data Type (ADT)
Abstract Data Type (ADT) adalah sebuah TYPE beserta sekumpulan PRIMITIF (operasi dasar) yang berlaku terhadap TYPE tersebut. Pada ADT yang lengkap, disertakan juga definisi invarian dari TYPE dan aksioma yang berlaku. ADT merupakan definisi yang bersifat STATIK. Definisi type dari sebuah ADT juga bisa mengandung ADT lain, misalnya ADT waktu yang terdiri dari ADT JAM dan ADT DATE, atau garis yang terdiri dari dua buah ADT POINT [1].

### B. Primitif pada ADT
TYPE diterjemahkan menjadi type yang terdefinisi dalam bahasa pemrograman yang dipakai, sedangkan PRIMITIF dalam konteks prosedural diterjemahkan menjadi fungsi atau prosedur. Primitif dikelompokkan menjadi beberapa jenis [1]:
1. Konstruktor/Kreator, untuk membentuk nilai type. Biasanya namanya diawali `Make`.
2. Selector, untuk mengakses komponen dari type. Biasanya namanya diawali `Get`.
3. Prosedur pengubah nilai komponen.
4. Validator komponen, untuk menguji apakah nilai yang diberikan dapat membentuk type sesuai batasan.
5. Destruktor/Dealokator, untuk "menghancurkan" nilai objek sekaligus memori penyimpanannya.
6. Baca/Tulis, untuk berinteraksi dengan *input/output device*.
7. Operator relasional, untuk mendefinisikan lebih besar, lebih kecil, sama dengan, dan sebagainya.
8. Aritmatika terhadap type tersebut.
9. Konversi dari type tersebut ke tipe dasar dan sebaliknya.

### C. Struktur File pada ADT
ADT biasanya diimplementasikan menjadi dua modul utama dan satu modul *driver* (program utama) [1]:
1. File header (`.h`), berisi definisi/spesifikasi type dan header dari primitif. Untuk fungsi dituliskan nama, domain, range, dan prekondisi jika ada. Untuk prosedur dituliskan *initial state*, *final state*, dan proses yang dilakukan.
2. File body (`.cpp`), berisi realisasi dari primitif yang sudah dideklarasikan di file header.
3. File `main.cpp`, sebagai program utama yang memanfaatkan ADT tersebut.

Pada file header biasanya dipasang `#ifndef`, `#define`, dan `#endif` (*include guard*) agar isi header tidak terbaca dua kali saat di-*include*.

### D. Array 2D dan Pointer
Array 2D pada C++ dideklarasikan dengan dua indeks, yaitu baris dan kolom, misalnya `int arr[3][3]`. Elemennya diakses dengan `arr[baris][kolom]`. Ketika array dikirim ke fungsi, yang dikirim adalah alamatnya, sehingga perubahan isi array di dalam fungsi ikut mengubah array aslinya. Pointer adalah variabel yang menyimpan alamat memori variabel lain. Operator `&` dipakai untuk mengambil alamat, dan operator `*` dipakai untuk mengakses nilai yang ditunjuk pointer.\

### 1. Program yang dapat menyimpan data mahasiswa (maksimal 10) ke dalam sebuah array dengan field nama, nim, uts, uas, tugas, dan nilai akhir. Nilai akhir diperoleh dari fungsi dengan rumus 0.3*uts + 0.4*uas + 0.3*tugas.

```C++
#include <iostream>
#include <string>
using namespace std;

const int MAX = 10;

struct mahasiswa {
    string nama;
    string nim;
    float uts, uas, tugas;
    float nilaiAkhir;
};

// fungsi untuk menghitung nilai akhir
float hitungNilaiAkhir(float uts, float uas, float tugas) {
    return 0.3 * uts + 0.4 * uas + 0.3 * tugas;
}

int main() {
    mahasiswa data[MAX];
    int n;

    cout << "Jumlah mahasiswa (max " << MAX << ") : ";
    cin >> n;
    if (n > MAX) n = MAX;
    if (n < 0) n = 0;

    for (int i = 0; i < n; i++) {
        cout << "\nData mahasiswa ke-" << i + 1 << endl;
        cin.ignore();
        cout << "Nama   : ";
        getline(cin, data[i].nama);
        cout << "NIM    : ";
        cin >> data[i].nim;
        cout << "UTS    : ";
        cin >> data[i].uts;
        cout << "UAS    : ";
        cin >> data[i].uas;
        cout << "Tugas  : ";
        cin >> data[i].tugas;
        data[i].nilaiAkhir = hitungNilaiAkhir(data[i].uts, data[i].uas, data[i].tugas);
    }

    cout << "\n=== Data Mahasiswa ===" << endl;
    for (int i = 0; i < n; i++) {
        cout << i + 1 << ". " << data[i].nama << " (" << data[i].nim << ")" << endl;
        cout << "   UTS: " << data[i].uts << ", UAS: " << data[i].uas
             << ", Tugas: " << data[i].tugas << endl;
        cout << "   Nilai Akhir: " << data[i].nilaiAkhir << endl;
    }

    return 0;
}
```

### 2. Membuat ADT pelajaran di dalam file "pelajaran.h", lengkap dengan implementasinya pada file "pelajaran.cpp" dan pengujiannya pada file "main.cpp".

##### pelajaran.h
```C++
#ifndef PELAJARAN_H_INCLUDED
#define PELAJARAN_H_INCLUDED

#include <string>
using namespace std;

struct pelajaran {
    string namaMapel;
    string kodeMapel;
};

pelajaran create_pelajaran(string namapel, string kodepel);
void tampil_pelajaran(pelajaran pel);

#endif // PELAJARAN_H_INCLUDED
```

##### pelajaran.cpp
```C++
#include <iostream>
#include "pelajaran.h"
using namespace std;

pelajaran create_pelajaran(string namapel, string kodepel) {
    pelajaran p;
    p.namaMapel = namapel;
    p.kodeMapel = kodepel;
    return p;
}

void tampil_pelajaran(pelajaran pel) {
    cout << "nama pelajaran : " << pel.namaMapel << endl;
    cout << "nilai : " << pel.kodeMapel << endl;
}
```

##### main.cpp
```C++
#include <iostream>
#include "pelajaran.h"
using namespace std;

int main() {
    string namapel = "Struktur Data";
    string kodepel = "STD";
    pelajaran pel = create_pelajaran(namapel, kodepel);
    tampil_pelajaran(pel);

    return 0;
}
```

### 3. Program dengan 2 buah array 2D integer berukuran 3x3 dan 2 buah pointer integer, dengan fungsi/prosedur untuk menampilkan isi array 2D, menukarkan isi 2 array 2D pada posisi tertentu, dan menukarkan isi variabel yang ditunjuk oleh 2 buah pointer.

```C++
#include <iostream>
using namespace std;

// menampilkan isi array 2D 3x3
void tampilArray(int arr[3][3]) {
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            cout << arr[i][j] << "\t";
        }
        cout << endl;
    }
}

// menukar isi 2 array 2D pada posisi (baris, kolom) tertentu
void tukarPosisi(int a[3][3], int b[3][3], int baris, int kolom) {
    int temp = a[baris][kolom];
    a[baris][kolom] = b[baris][kolom];
    b[baris][kolom] = temp;
}

// menukar isi variabel yang ditunjuk 2 pointer
void tukarPointer(int *p1, int *p2) {
    int temp = *p1;
    *p1 = *p2;
    *p2 = temp;
}

int main() {
    int A[3][3] = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
    int B[3][3] = {{11, 12, 13}, {14, 15, 16}, {17, 18, 19}};
    int x = 10, y = 20;
    int *p1 = &x;
    int *p2 = &y;
    int baris, kolom;

    cout << "Array A:" << endl;
    tampilArray(A);
    cout << "\nArray B:" << endl;
    tampilArray(B);

    cout << "\nTukar isi A dan B pada posisi (baris kolom, mulai dari 0): ";
    cin >> baris >> kolom;
    if (baris < 0 || baris > 2 || kolom < 0 || kolom > 2) {
        cout << "Posisi tidak valid." << endl;
    } else {
        tukarPosisi(A, B, baris, kolom);
        cout << "\nSetelah ditukar" << endl;
        cout << "Array A:" << endl;
        tampilArray(A);
        cout << "\nArray B:" << endl;
        tampilArray(B);
    }

    cout << "\nSebelum tukar pointer : x = " << *p1 << ", y = " << *p2 << endl;
    tukarPointer(p1, p2);
    cout << "Sesudah tukar pointer : x = " << *p1 << ", y = " << *p2 << endl;

    return 0;
}
```
